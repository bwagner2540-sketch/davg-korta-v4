### Website copy

#### Build the network around the property

Internet service brings a connection to the home. The network determines how that connection and the home’s systems reach the places they are needed.

##### Improve the existing network

Address a focused coverage, placement or configuration problem.

- Test the connection and the in-home network separately.
- Work with useful existing cabling and equipment.

##### A wired, managed foundation

Plan access points, switching and fixed connections as a coordinated residential network.

- Use wired backhaul where practical.
- Separate networks where the system and household require it.
- Organize equipment, power and documentation.

##### A more extensive property network

Extend the design across larger areas, exterior spaces or detached buildings.

- Survey materials, distances and available pathways.
- Plan building-to-building connections and outdoor coverage.
- Test with realistic household traffic.

Equipment is selected after the coverage and capacity brief is clear. Support arrangements can be added to match the household’s needs.
