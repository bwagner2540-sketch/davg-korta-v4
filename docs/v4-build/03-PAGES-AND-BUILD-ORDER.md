# Current routes

Status: documented 3 October 2026. This note matches the routes that exist. It is not a migration plan.

Public service URLs are `/solutions/<slug>/`, written in each git hub and generated by `src/pages/solutions/[slug].astro`. `/systems/<slug>/` renders the same `HubPage.astro`. `/solutions/` redirects to `/systems/`. The ordered labels live in `src/config/site.ts`.

The eight hubs are already rendered from `docs/v4-build/hubs/DAVG-V4-Hub-*.md`. Do not rename them from an older taxonomy, and do not move the public route from `/solutions/` to `/systems/`.

The homepage is `src/pages/index.astro`. A real 404 source exists. No other marketing, support, project, city, legal, or legacy redirect page is recorded here as a finished release.

Earlier build-order notes are in `archive/davg-history/docs-v4-build-archive/checkpoint-dc9ff37/03-PAGES-AND-BUILD-ORDER.md`. They are not the current route map.
