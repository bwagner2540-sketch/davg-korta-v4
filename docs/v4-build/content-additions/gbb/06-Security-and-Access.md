## Put in Section 06 — Choose events, cameras and credentials

Module ID: `security-recording-options`

**Placement:** Replace the existing local / cloud / hybrid comparison with this module; keep event, detail, credential and privacy guidance.

### Website copy

#### Choose where recordings live

Recording location changes ownership, access and ongoing cost. Choose it alongside the events you need to see and the areas you want to keep private.

##### Local recording

Store footage on a recorder at the property.

- Plan retention, equipment access and user permissions.
- Separate remote access requirements from local recording behavior.

##### Cloud-connected recording

Use a supported cloud service for the access and management functions the project needs.

- Understand subscription, retention and export terms.
- Confirm what continues if the internet connection is unavailable.

##### A deliberate hybrid

Combine local and cloud functions where that combination solves a clear requirement.

- Document what is stored in each place.
- Keep account ownership and access permissions understandable.

Cloud storage is not automatically an upgrade over local storage. The right choice follows the household’s privacy, access and continuity priorities.

## Put in Section 12 — What changes security investment?

Module ID: `security-property-scopes`

**Placement:** Add after the existing security investment introduction. Replace price/package cards; do not replace the camera coverage and credentials chapters.

### Website copy

#### Choose the property scope

Start with the places and events that matter. Add equipment only where it has a defined purpose.

##### Entry visibility

Focus on a main approach, door or other priority entry.

- Choose the image detail required at that location.
- Set recording, alerts and household access.

##### Property coverage

Coordinate several views and entry points across the residence.

- Resolve day and night conditions, retention and camera placement.
- Plan network, power, cable routes and privacy exclusions.

##### Integrated access and coverage

Bring selected cameras, doors, gates and supported control responses into one plan.

- Define credentials and who can change them.
- Coordinate entry hardware, backup behavior and system interfaces.

The proposal separates cameras, recording, door or gate equipment, infrastructure, installation and ongoing service choices.
